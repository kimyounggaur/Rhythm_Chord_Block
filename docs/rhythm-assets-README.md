# 리듬 블록 게임 에셋 v0.1

**결론부터:** 설계서(`rhythm-tetris-design-v0.1.md`)에 맞춘, 귀엽고 말랑한 "젤리" 스타일 그림 **159개**가 들어 있어요.
모두 SVG(크기를 늘려도 안 깨지는 그림)이고, 앱 아이콘만 PNG도 함께 있어요. 글자는 전부 도형으로 바뀌어 있어서 **글꼴을 따로 설치할 필요가 없어요.**

- 전체를 한눈에 보려면 `preview.html`을 브라우저로 열어 보세요. (이 폴더 안에서 열어야 그림이 보여요)
- 게임 화면에 조립한 모습은 `preview/game-screen.png`, 분류별 모아보기는 `preview/overview-*.png` 예요.
- 색·크기 이름표는 `tokens.css`, 파일 목록(크기 포함)은 `manifest.json` 에 있어요.

## 약속(규칙) — 설계서와 맞춘 것

1. **한 칸 = 8분음표 한 개.** k칸짜리 알약 = 길이 k인 음 (2칸=4분음표, 3칸=점4분음표, 4칸=2분음표, 8칸=온음표).
2. **계이름 ↔ 조각 ↔ 색** (설계서 §4.3과 같은 값):

   | 계이름 | 영어 | 조각 | 색 |
   |---|---|---|---|
   | 도 | C | I | `#E53935` 빨강 |
   | 레 | D | O | `#FB8C00` 주황 |
   | 미 | E | T | `#FDD835` 노랑 |
   | 파 | F | S | `#43A047` 초록 |
   | 솔 | G | Z | `#1E88E5` 파랑 |
   | 라 | A | J | `#3949AB` 남색 |
   | 시 | B | L | `#8E24AA` 보라 |

3. **타일 글자:** `-label` 파일은 계이름 글자가 들어 있어요. 색만으로 구분이 어려운 사람에게 도움이 되고, 배우는 데도 좋아요. 글자 없는 파일은 앱에서 글자를 따로 얹을 때 쓰세요.
4. **고스트**(떨어질 자리 미리보기)는 테두리만 있어요. 진짜 조각과 헷갈리지 않게 하려는 거예요.
5. **알약**은 "줄이 지워질 때 같은 음의 칸이 합쳐진 모양"으로만 쓰세요. 2·3·4칸이 들어 있고, 더 긴 알약(8칸 온음표 등)이 필요하면 AI에게 `tools/tiles.py` 의 `pill_body` 로 만들어 달라고 하세요. (`stages/stage7.svg` 에 8칸 예시가 있어요)
6. **보드:** 4/4 기준 8×16칸, 한 칸 34px → 272×544 (화면 360×780). 박자마다 가로 칸 수만 달라요:

   | 박자 | 파일 | 가로 칸 | 칸 34px일 때 가로 |
   |---|---|---|---|
   | 4/4 | `board-4-4` | 8 | 272 |
   | 3/4 | `board-3-4` | 6 | 204 |
   | 6/8 | `board-6-8` | 6 | 204 |
   | 9/8 | `board-9-8` | 9 | 306 |
   | 12/8 | `board-12-8` | 12 | 408 (화면보다 넓음 → 칸을 줄여 쓰세요) |
   | 5/4 | `board-5-4` | 10 | 340 |
   | 7/8 | `board-7-8` | 7 | 238 |

   보드 배경은 박 점선, 마디 중간 세로줄, 왼쪽 굵은 마디줄이 그려져 있어요. 6/8·9/8·12/8·5/4·7/8 은 묶음마다 배경 띠가 번갈아 나와요. `-beats` 파일은 센박 열이 더 밝아요(스테이지 3부터).
7. **새로 만든 그림만 썼어요.** 원작 게임의 이름·모양·캐릭터는 쓰지 않았고, 파일 이름에도 넣지 않았어요. 마스코트 '똑딱이'는 새로 만든 캐릭터예요(이름은 제안).

## 쓰는 법 (직접 쓰거나, 개발 AI에게 이 문서를 보여 주세요)

```html
<!-- 타일 한 칸 (34px) -->
<img src="tiles/tile-do-label.svg" width="34" height="34" alt="도">
<!-- k칸 알약: 가로 = k × 34 -->
<img src="pills/pill-mi-3-label.svg" width="102" height="34" alt="미 3칸">
<!-- 보드 배경 + 박 번호 띠 -->
<img src="board/beatnum-4-4.svg" width="272" height="32">
<img src="board/board-4-4-beats.svg" width="272" height="544">
```

```js
// 캔버스: 보드 왼쪽 위가 (0,0)일 때 row 행, col 열의 칸
const img = new Image(); img.src = 'tiles/tile-do-label.svg';
img.onload = () => ctx.drawImage(img, col * 34, row * 34, 34, 34);
```

- 타일 그림은 96칸 안에서 가장자리 3만큼 띄워 그려 둬서, 붙여 놓아도 칸 사이에 가는 틈이 생겨요. 의도한 거예요.
- 조작 버튼은 `pointerdown` 때 `-pressed` 파일로 바꾸세요.
- `fx/fx-line-flash.svg` 는 가로로 늘려서 지워지는 줄 위에 얹고, 불투명도를 줄이면서 사라지게 하세요.
- 앱 아이콘(웹앱): `app-icon-192.png`, `app-icon-512.png` 는 일반용, `app-icon-maskable-*.png` 는 `purpose: "maskable"`로 등록하세요. 아이폰 홈 화면은 `app-icon-180.png`.
- 색을 쓸 때는 `tokens.css` 의 이름(예: `var(--pitch-do)`)을 쓰면 에셋과 똑같은 색이에요.

개발 AI에게 이렇게 말하면 돼요:
- "`tiles/` 의 SVG로 8×16 보드를 그려 줘. 한 칸 34px이고, `board/board-4-4-beats.svg` 를 배경으로 깔아 줘."
- "조작 버튼은 `controls/` 의 SVG를 쓰고, 누르는 동안 `-pressed` 로 바꿔 줘."
- "줄이 지워지면 그 줄의 칸을 `pills/` 알약으로 바꾸고 `fx/` 반짝이를 띄워 줘."

## 고치거나 다시 만들기

그림은 코드(`tools/`)로 만들었어요. 색이나 모양을 바꾸고 싶으면 AI에게 "tools 에서 ○○를 고치고 다시 빌드해 줘"라고 하면 돼요.

```
pip install fonttools          # 글자를 도형으로 바꾸는 데 필요
python3 tools/build.py         # 이 폴더의 모든 그림·미리보기·목록을 다시 만든다 (rsvg-convert 필요)
```

- 계이름 색·화면 색: `tools/common.py` 맨 위의 `PITCHES`, `C`
- 타일·알약·보드: `tiles.py` / 버튼·아이콘·배지: `ui.py` / 이펙트·마스코트: `fx.py` / 배경·앱 아이콘: `scenes.py` / 스테이지 그림: `stages.py` / 게임 화면 조립: `compose.py`
- `build.py` 는 정해진 폴더(`tiles`, `pills` …)만 지우고 다시 만들어요. 이 설명서의 틀은 `tools/README.template.md` 예요.
- 글꼴에 없는 글자를 쓰면 오류(KeyError)가 나요. 다른 글자로 바꾸세요.

## 확인한 것 / 못 한 것

**확인한 것 (2026-11-03)**
- SVG 전부 XML 문법 검사 통과, 글자(`<text>`)·외부 링크·스크립트 없음, id 중복·끊긴 참조 없음.
- 분류별로 모아서 그려 눈으로 확인했어요: 타일(글자 있음/없음)·고스트·알약·박자별 보드·버튼·아이콘·배지·이펙트·마스코트·배경·스테이지 카드·앱 아이콘, 그리고 게임 화면 조립.
- 크롬(Chromium) 브라우저에서 SVG 전부(미리보기 포함 160개)가 오류 없이 열렸고, 게임 화면이 다른 그림 도구(rsvg)와 거의 똑같이 그려졌어요(크게 다른 픽셀 0.01%).

**못 한 것 (직접 확인이 필요해요)**
- 실제 폰(아이폰·안드로이드)과 실제 앱 안에서 보이는 모습·속도는 확인하지 못했어요.
- 색각 이상(색약)에서 어떻게 보이는지는 따로 검사하지 않았어요. (계이름 글자로 대비해 두었어요)
- 마스코트 이름 '똑딱이'와 글꼴(Jua) 선택은 제 제안이에요. 바꾸고 싶으면 알려 주세요.
