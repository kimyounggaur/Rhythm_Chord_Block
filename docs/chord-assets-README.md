## 약속(규칙) — 설계서와 맞춘 것

1. **계이름 ↔ 색** (설계서 §4.2와 같은 값, 리듬 게임과도 같음):

   | 계이름 | 영어 | 색 |
   |---|---|---|
   | 도 | C | `#E53935` 빨강 |
   | 레 | D | `#FB8C00` 주황 |
   | 미 | E | `#FDD835` 노랑 |
   | 파 | F | `#43A047` 초록 |
   | 솔 | G | `#1E88E5` 파랑 |
   | 라 | A | `#3949AB` 남색 |
   | 시 | B | `#8E24AA` 보라 |

2. **화음 ↔ 구성음 ↔ 받침대 색** (타일 색과 겹치지 않게 골랐어요):

   | 화음 | 구성음 | 받침대·배지 색 |
   |---|---|---|
   | Ⅰ 으뜸화음 | 도·미·솔 | `#FFC107` 금색 |
   | Ⅳ 버금딸림화음 | 파·라·도 | `#26A69A` 청록 |
   | Ⅴ 딸림화음 | 솔·시·레 | `#AB47BC` 자주 |
   | Ⅴ7 딸림7화음(확장) | 솔·시·레·파 | 딸림과 같은 자주 + **점선 테두리** |

   그림 안의 로마 숫자는 영문자(`I`·`IV`·`V`·`V7`, 단조는 소문자 `i`·`iv`)로 그렸어요. 쓰인 글꼴(Jua)에 Ⅰ·Ⅳ·Ⅴ 문자가 없어서예요. 앱 화면의 글자는 자유롭게 Ⅰ·Ⅳ·Ⅴ 로 써도 돼요.
3. **타일 종류.** 보통 타일은 `-label`(계이름 글자 포함, 기본으로 쓰세요)과 글자 없는 것이 있어요. 색만으로 구분이 어려운 사람에게도 글자가 도움이 돼요.
   - **잠든 타일**(`tile-계이름-dim`): 지금 스테이지에서 켜진 화음에 없는 음(스테이지 1은 레·파·라·시, 스테이지 2는 파·라). 터지지 않고, 옆 덩어리가 터질 때 같이 사라져요. 흐린 색 + 점선 + `z z` 로 "지금은 안 터져요"를 알려요. 계이름 글자는 그대로 있어요.
   - **방해 타일**(`tile-junk`): 회색, ♯♭ 표시. 스테이지 8부터. 옆 화음이 터질 때 같이 사라져요.
   - **솔♯**(`tile-sol-sharp`): 스테이지 10(가단조 확장)용. 색(`#00ACC1` 청록 계열)은 설계서에 지정이 없어서 제가 제안한 값이에요.
4. **보드:** 7×14칸(보이는 줄만), 한 칸 38px → 266×532 (화면 360×780, 설계서 §13). `board/board-7x14.svg` 는 칸 96 단위로 그려져 있어서 `칸크기 ÷ 96` 배로 줄여 쓰세요. 가운데 열(조각이 나오는 열)이 살짝 밝아요. 설계서의 "(3,1)에 흐린 ×"는 `board/mark-spawn-x.svg` 를 그 칸에 얹으면 돼요.
5. **만들지 않은 것:** 고스트(떨어질 자리 미리보기)·보관(hold) 버튼·맨 위 숨은 줄 표시는 설계서에 없어서 그림이 없어요.
6. **새로 만든 그림만 썼어요.** 원작 게임의 이름·모양·캐릭터를 쓰지 않았고 파일 이름에도 넣지 않았어요. 게임 이름이 아직 정해지지 않아서(설계서 §19) 파일 안 글에는 이름이 들어 있지 않아요.

## 덩어리 받침대 (`groups/`) — 이 게임의 핵심

설계서 §14-2: 같은 화음으로 이어진 타일(2개 이상)에는 화음 색 테두리를 그려요. 그림 하나하나를 이어 붙이는 계산이 필요 없게, **타일 뒤에 칸마다 받침대를 한 장씩 깔기만 하면** 되도록 만들었어요. 이웃한 받침대끼리 겹쳐서 타일 사이 틈까지 같은 색으로 채워지고, 이어진 덩어리가 하나의 판 위에 놓인 것처럼 보여요.

- 받침대 그림은 120×120이고, **가운데 96×96이 한 칸**이에요. 칸 크기가 `cs`이면 `s = cs / 96` 배로 줄이고, 칸의 왼쪽 위 `(x, y)`에서 `(−12·s, −12·s)` 만큼 당겨 얹으세요. (38px 칸이면 크기 47.5px, 왼쪽 위로 4.75px)
- **공통음 타일**은 두 화음에 모두 속해요. 도(Ⅰ·Ⅳ), 솔(Ⅰ·Ⅴ). 이 칸에는 두 색이 대각선으로 반반인 받침대(`halo-i-iv`, `halo-i-v`)를 쓰세요. 두 덩어리가 모두 크기 2 이상일 때만 반반이에요. 스테이지 9에서는 솔(Ⅰ·Ⅴ7)과 파(Ⅳ·Ⅴ7)용 `halo-i-v7`, `halo-iv-v7` 도 있어요.
- **그리는 순서:** ① 받침대(모든 칸) → ② 타일 → ③ 힌트 배지 → ④ 떨어지는 조각 → ⑤ 이펙트. 받침대를 먼저 모두 깔아야 이웃끼리 자연스럽게 겹쳐요.
- 어떤 칸에 어떤 받침대를 깔지는 "화음마다 위·아래·좌·우로 이어진 같은 화음 음 덩어리를 찾기"로 정해요. `tools/chord.py` 의 `find_groups` / `halo_map` 이 그 코드이고, 자바스크립트로 옮기면 이래요:

```js
// TONES 에는 '지금 스테이지에서 켜진 화음'만 넣으세요 (스테이지 1은 I 만, 스테이지 2는 I·V).
// 스테이지 9는 V 대신 V7: ['sol','si','re','fa'] — 그러면 ['I','V7'], ['IV','V7'] 도 나와요.
const TONES = { I: ['do','mi','sol'], IV: ['fa','la','do'], V: ['sol','si','re'] };
// grid: Map("col,row" → 계이름) — 보드에 있는 타일 전부. 잠든 타일(켜진 화음에 없는 음)은 저절로 어느 덩어리에도 안 들어가요.
function haloNames(grid) {
  const names = new Map();                      // "col,row" → ['I'] 또는 ['I','IV'] …
  for (const [id, tones] of Object.entries(TONES)) {
    const seen = new Set();
    for (const [key, pid] of grid) {
      if (seen.has(key) || !tones.includes(pid)) continue;
      const comp = [], stack = [key];
      while (stack.length) {
        const k = stack.pop();
        if (comp.includes(k) || !tones.includes(grid.get(k))) continue;
        comp.push(k);
        const [c, r] = k.split(',').map(Number);
        stack.push(`${c + 1},${r}`, `${c - 1},${r}`, `${c},${r + 1}`, `${c},${r - 1}`);
      }
      comp.forEach(k => seen.add(k));
      if (comp.length >= 2) comp.forEach(k => names.set(k, [...(names.get(k) || []), id]));
    }
  }
  return names;    // ['I'] → groups/halo-i.svg, ['I','IV'] → halo-i-iv.svg, ['I','V'] → halo-i-v.svg
}
```

## 쓰는 법 (직접 쓰거나, 개발 AI에게 이 문서를 보여 주세요)

```html
<!-- 타일 한 칸 (38px) -->
<img src="tiles/tile-do-label.svg" width="38" height="38" alt="도">
<!-- 보드 배경 (칸 96 단위 → 38px 이면 266×532) -->
<img src="board/board-7x14.svg" width="266" height="532">
```

```js
// 캔버스: 보드 왼쪽 위가 (0,0)일 때 col 열, row 줄(0부터)의 칸
const CELL = 38, S = CELL / 96, x = col * CELL, y = row * CELL;
ctx.drawImage(halo,  x - 12 * S, y - 12 * S, 120 * S, 120 * S);   // ① 받침대 (모든 칸 먼저)
ctx.drawImage(tile,  x, y, CELL, CELL);                           // ② 타일
```

- 타일 그림은 96칸 안에서 가장자리 3만큼 띄워 그려 둬서, 붙여 놓아도 칸 사이에 가는 틈이 생겨요. 의도한 거예요(받침대가 그 틈을 메워요).
- 조작 버튼은 `pointerdown` 때 `-pressed` 파일로 바꾸세요.
- 터짐 연출: 터질 타일 위에 `fx/fx-tile-flash.svg` → 그 타일 색의 `fx/fx-shards-계이름.svg` 를 키우며 퍼지게 → 화음 색 `fx/fx-burst-화음.svg`(i·iv·v)를 덩어리 가운데에서 펼치기. 연쇄는 `fx/fx-ring.svg`.
- 앱 아이콘(웹앱): `app-icon-192.png`, `app-icon-512.png` 는 일반용, `app-icon-maskable-*.png` 는 `purpose: "maskable"`로 등록하세요. 아이폰 홈 화면은 `app-icon-180.png`.
- 색을 쓸 때는 `tokens.css` 의 이름(예: `var(--pitch-do)`, `var(--chord-i)`)을 쓰면 에셋과 똑같은 색이에요.

개발 AI에게 이렇게 말하면 돼요:
- "`board/board-7x14.svg` 를 38px 칸으로 깔고, 타일은 `tiles/` 의 `-label` 파일을 써 줘."
- "같은 화음으로 이어진 타일에는 README 의 `haloNames` 처럼 칸마다 `groups/` 받침대를 먼저 깔아 줘. 공통음 칸은 반반 받침대로."
- "크기 3 이상 덩어리에서 구성음이 하나 빠지면 `hints/` 배지를 맨 위 타일 오른쪽 위에 얹어 줘."

## 고치거나 다시 만들기

그림은 코드(`tools/`)로 만들었어요. 색이나 모양을 바꾸고 싶으면 AI에게 "tools 에서 ○○를 고치고 다시 빌드해 줘"라고 하면 돼요.

```
pip install fonttools          # 글자를 도형으로 바꾸는 데 필요
python3 tools/build.py         # 이 폴더의 모든 그림·미리보기·목록을 다시 만든다 (rsvg-convert 필요)
```

- 계이름 색·화음 색·화면 색: `tools/common.py` 맨 위의 `PITCHES`, `CHORDS`, `C`
- 타일·보드: `tiles.py` / **받침대·화음 배지·힌트·음정·진행 띠·도감 카드**: `chord.py` / 버튼·아이콘: `ui.py` / 이펙트·마스코트: `fx.py` / 배경·앱 아이콘: `scenes.py` / 스테이지 그림: `stages.py` / 게임 화면 조립(보드 배치·힌트 계산 예시 포함): `compose.py`
- `build.py` 는 정해진 폴더(`tiles`, `groups` …)만 지우고 다시 만들어요. 이 설명서의 틀은 `tools/README.template.md` 예요.
- 글꼴에 없는 글자를 쓰면 오류(KeyError)가 나요. 다른 글자로 바꾸세요.
